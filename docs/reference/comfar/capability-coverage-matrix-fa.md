# ماتریس جامع پوشش قابلیت‌های COMFAR در پیشران

این ماتریس از ساختار Reference Manual، فهرست سریع آن، و مراحل عملی Tutorial Manual استخراج شده است. هدف، تبدیل هر موضوع راهنما به یک قابلیت قابل انتخاب، ورودی، الگوریتم، گزارش یا آزمون پذیرش در پیشران است. این سند فهرست نیازمندی‌هاست؛ ثبت یک قابلیت در این جدول به معنی تکمیل پیاده‌سازی آن نیست.

## 1. شناسایی پروژه و تعیین سطح مطالعه

| موضوع راهنما | نیاز در پیشران | وضعیت/اقدام |
|---|---|---|
| Project type و Project classification | صنعتی، غیرصنعتی، معدن/فرآوری، خدمات، زیرساخت و سایر ساختارهای قابل تعریف | باید مدل داده و فرم‌های وابسته به نوع پروژه داشته باشد |
| Opportunity / feasibility / detailed study | انتخاب سطح مطالعه و کنترل حداقل داده لازم در هر سطح | طراحی گردش‌کار و اعتبارسنجی مرحله‌ای |
| Project status | پروژه جدید، توسعه، نوسازی، بازسازی، توسعه+نوسازی، واحد در حال ساخت/بهره‌برداری | انتخاب توسعه/نوسازی در فرم اصلی اضافه شده |
| Special features | تورم، مشارکت مشترک، تحلیل اقتصادی، توسعه/نوسازی و قابلیت‌های ویژه | فهرست گزینه‌ها باید مستقل از نوع پروژه فعال شود |
| Project identification | عنوان، شناسه، کشور/موقعیت، سرمایه‌گذار، شرح، تاریخ‌ها، ارز و منابع | بخشی در فرم تعریف پروژه؛ تکمیل metadata و audit trail لازم |
| Planning horizon | دوره ساخت، راه‌اندازی، افزایش ظرفیت تدریجی، تولید کامل، دوره بهره‌برداری، افق تحلیل و سال مرجع | افق دوره‌ای قابل تنظیم؛ تقویم‌های ماهانه/فصلی نیز باید پشتیبانی شوند |
| Products | چند محصول و محصول فرعی، واحد اندازه‌گیری، ظرفیت، کیفیت و ترکیب فروش | فهرست محصولات موجود؛ تکمیل مشخصات محصول/محصول جانبی |
| Currencies | ارز محلی و خارجی، ارز مرجع، نرخ تبدیل اولیه و آتی، سهم ارزی اقلام | فرم چندارزی کامل و ترجمه به ارز مرجع نیازمند توسعه |
| Discounting | نرخ تنزیل کل سرمایه، حقوق صاحبان سهام، شریک، نرخ تأمین مالی و سرمایه‌گذاری مجدد | NPV/IRR/MIRR و WACC موجود؛ تقویم دوره‌ای و قواعد تاریخ ارزش باید تکمیل شود |

## 2. ورودی‌های مالی و عملیاتی

| موضوع راهنما | پوشش لازم |
|---|---|
| Fixed investment costs | طبقه‌بندی اقلام سرمایه‌گذاری، محلی/ارزی، زمان‌بندی پرداخت، مالیات و عوارض، هزینه حمل/نصب، زیرساخت، ماشین‌آلات، زمین، ساختمان، پیش‌بینی‌نشده و هزینه‌های قبل از بهره‌برداری |
| Annual adjustments | تعدیل سالانه/دوره‌ای مقدار، قیمت، نرخ ارز، عمر/بهره‌برداری و زمان‌بندی دارایی‌ها |
| Production costs | هزینه‌های استاندارد و مستقیم/غیرمستقیم، ثابت/متغیر، محلی/ارزی، به تفکیک محصول و مرکز هزینه |
| Standard production costs | مواد اولیه، مواد کمکی، انرژی، قطعات یدکی، نیروی انسانی، سربار، تعمیرات و هزینه‌های عمومی کارخانه |
| Cost allocation | مراکز هزینه، کلیدهای تخصیص کاربر، تخصیص هزینه مشترک و سهم هر محصول/واحد |
| Sales programme | مقدار فروش هر محصول در هر دوره، قیمت، بازار داخلی/صادرات، مالیات فروش، یارانه قیمت، رشد/تعدیل قیمت و محدودیت تقاضا |
| Production programme | تولید مشتق از فروش و تغییر موجودی محصول نهایی؛ ظرفیت، بازده، ضایعات، ramp-up و توقف تولید |
| Working capital | موجودی مواد، WIP، محصول نهایی، دریافتنی، وجه نقد، سپرده، پرداختنی، روزهای نگهداری/وصول/پرداخت و بازیافت انتهای افق |
| Sources of finance | آورده، سهام ممتاز/عادی، وام‌های متعدد، کمک بلاعوض، یارانه، تسهیلات کوتاه‌مدت و بلندمدت، ارز و برداشت دوره‌ای |
| Long-term loans | نوع وام، نرخ ثابت/متغیر، مبلغ و تاریخ برداشت، دوره تنفس، تناوب بهره، تاریخ اولین قسط، تعداد اقساط، روش اصل مساوی/اقساط مساوی/یکجا، کارمزد، بهره سرمایه‌ای و مانده بدهی |
| Short-term loans and cash deficits | تأمین کسری نقدینگی دوره‌ای، سقف اعتبار، بهره، بازپرداخت و گردش تسهیلات کوتاه‌مدت |
| Profit distribution | سود تقسیمی عادی/ممتاز، درصد/سیاست تقسیم سود، سود انباشته، پرداخت به شرکا و بازگشت سرمایه |
| Taxes and allowances | مالیات عملکرد، نرخ‌های پلکانی، تعطیلات مالیاتی، زیان انتقالی، معافیت، استهلاک مالیاتی، مالیات فروش، عوارض واردات/صادرات و مالیات غیرمستقیم |
| Depreciation | روش‌های خط مستقیم، مانده نزولی و سایر روش‌های مجاز، عمر مفید، ارزش اسقاط، زمان شروع، تعدیل/تجدید ارزیابی و فروش دارایی |
| Inflation | مدل با قیمت ثابت و جاری، شاخص‌های قیمت، تورم محلی/ارزی و تفکیک افزایش واقعی از تورم |

## 3. پروژه توسعه/نوسازی بنگاه موجود

| موضوع | نیازمندی |
|---|---|
| Opening balances | مانده افتتاحیه دارایی جاری، بدهی جاری، WIP، موجودی محصول، دریافتنی، نقد، سپرده، پرداختنی |
| Fixed asset opening balances | بهای تمام‌شده، استهلاک انباشته، ارزش دفتری، عمر باقیمانده، ارزش فرصت/بازار و وضعیت دارایی |
| Long-term finance opening balances | مانده وام، بهره معوق، سررسید و برنامه خدمت بدهی موجود |
| Equity opening balances | سرمایه، اندوخته، سود/زیان انباشته، کمک و یارانه |
| Opportunity cost | ارزش بازار مستقل/ترکیبی یا ارزش فعلی بهترین کاربرد جایگزین دارایی‌های موجود |
| With/without/incremental | محاسبه جداگانه بنگاه بدون طرح، بنگاه با طرح و اثر افزایشی دوره‌به‌دوره |
| Shutdown and displacement | توقف تولید، تولید ازدست‌رفته، هزینه فرصت، نصب و راه‌اندازی، اثر بر خطوط موجود |
| Replacement and disposal | خروج دارایی قدیمی، عواید فروش، ارزش دفتری، سود/زیان فروش، مالیات و ورود دارایی جدید |
| Existing capacity | ظرفیت و تولید تاریخی، افت عملکرد، محدودیت عمر و سرمایه‌گذاری نگهدارنده در حالت بدون طرح |
| Incremental financing | تفکیک بدهی/آورده موجود از منابع مالی اختصاصی طرح جدید |

## 4. تحلیل اقتصادی و اجتماعی

| موضوع راهنما | قابلیت موردنیاز |
|---|---|
| Economic analysis scope | انتخاب تحلیل هزینه-فایده یا ارزش افزوده و سطح عمق تحلیل |
| Economic currencies and numeraire | ارز مرجع اقتصادی، نرخ رسمی و نرخ سایه ارز، تبدیل ارز محلی/خارجی |
| Traded / tradable / non-traded | طبقه‌بندی اقلام وارداتی، صادراتی، قابل تجارت و غیرقابل تجارت |
| Border prices | قیمت CIF/FOB، حمل داخلی، جابه‌جایی، هزینه بندری و قیمت مرزی |
| Standard conversion factors | ضریب تبدیل استاندارد و ضرایب اختصاصی برای نهاده/محصول |
| Disaggregation | تجزیه محتوای ارزی و داخلی اقلام تا چند سطح برای تحلیل ارزش افزوده |
| Indirect taxes and subsidies | حذف/تعدیل مالیات‌ها، عوارض و یارانه‌ها در قیمت اقتصادی |
| Labour shadow pricing | تفکیک نیروی کار ماهر/غیرماهر، دستمزد بازار و هزینه فرصت نیروی کار |
| Employment effects | اشتغال مستقیم و غیرمستقیم و شاخص‌های اثر اشتغال |
| Externalities | منافع و هزینه‌های بیرونی، آثار محیط‌زیستی و اجتماعی |
| Indirect monetary effects | منافع/هزینه‌های غیرمستقیم پولی و غیرپولی |
| Foreign exchange effect | جریان خالص ارز، صرفه‌جویی واردات، صادرات و نیاز ارزی |
| Cost-benefit analysis | جریان اقتصادی، NPV اقتصادی، نرخ بازده اقتصادی و تحلیل توزیعی |
| Value-added analysis | ارزش افزوده ناخالص/خالص، دستمزد، مازاد عملیاتی، مالیات و توزیع ارزش افزوده |

## 5. نتایج، گزارش‌ها و نمودارها

- جریان نقدی برنامه‌ریزی مالی و کل منابع/مصارف
- جریان نقدی تنزیل‌شده کل سرمایه، حقوق صاحبان سهام و شرکای سرمایه‌گذار
- صورت سود و زیان خالص و نسبت‌های آن
- ترازنامه، خالص دارایی‌ها، بدهی و حقوق مالکانه
- هزینه‌های تولید به تفکیک محصول، مرکز هزینه، ثابت/متغیر و محلی/ارزی
- برنامه تولید، فروش و موجودی
- سرمایه‌گذاری ثابت و مخارج پیش از بهره‌برداری
- برنامه منابع مالی، برداشت و بازپرداخت وام
- مالیات، سود تقسیمی و سود انباشته
- نیاز سرمایه در گردش و گردش اقلام آن
- بهای تمام‌شده و سودآوری هر محصول
- نقطه سربه‌سر و حاشیه ایمنی
- NPV، IRR، MIRR، دوره بازگشت ساده و تنزیل‌شده
- نسبت‌های کارایی و شاخص‌های مالی/اقتصادی
- جداول و نمودارهای ارزی، محلی/خارجی و ثابت/متغیر
- مقایسه چند پروژه/سناریو و نمودارهای با/بدون طرح
- گزارش قابل چاپ، خروجی PDF و خروجی جدولی با حفظ واحد، ارز، تاریخ و مبنای دوره

## 6. حساسیت، تحلیل پارامتریک و نقطه هدف

| روش COMFAR | پیاده‌سازی موردنیاز در پیشران |
|---|---|
| Global sensitivity | تغییر درصدی مقادیر/قیمت‌های اقلام CAPEX، OPEX و فروش، با ثبت سناریوی مبنا و نسخه تغییر یافته |
| Desired IRR | یافتن مقدار پارامتر یا مجموعه پارامترها برای رسیدن به IRR هدف، با کران تغییر و کنترل جهت اثر |
| Desired NPV | یافتن مقدار پارامتر یا مجموعه پارامترها برای رسیدن به NPV هدف |
| Parametric chart analysis | تغییر یک متغیر در هر نمودار و نمایش اثر آن بر شاخص‌های انتخابی |
| Multivariable sensitivity | ماتریس دو/چندمتغیره همراه با محاسبه مجدد مالیات، سرمایه در گردش، تأمین مالی و خدمت بدهی |
| Scenario analysis | سناریوهای پایه، خوش‌بینانه، بدبینانه و سناریوهای سفارشی با مفروضات قابل ردیابی |
| Break-even analysis | قیمت، حجم، ظرفیت بهره‌برداری و هزینه سربه‌سر به تفکیک محصول/مرکز هزینه |
| Compare | مقایسه نسخه‌های پروژه و سناریوها، نه فقط مقایسه نموداری بدون حفظ فرضیات |

نکته روش‌شناختی: راهنمای COMFAR تصریح می‌کند که تحلیل پارامتریک نمودار، فقط یک پارامتر را تغییر می‌دهد و تعامل آن با کسری/مازاد نقد، سرمایه در گردش و تأمین مالی را محاسبه نمی‌کند. پیشران باید این محدودیت را به کاربر اعلام کند و برای تحلیل اثرات تعاملی، از موتور کامل حساسیت استفاده کند.

## 7. ذخیره، گردش‌کار و قابلیت استفاده

- ذخیره ورودی‌ها جدا از نتایج محاسبه‌شده و امکان بازگشت به نسخه قبلی
- ذخیره با نام جدید/نسخه جدید و ثبت تاریخچه تغییرات
- ساختار مرورگر مرحله‌ای برای داده‌های پروژه و ساختار مجزا برای نتایج
- انتخاب دقیق گزارش‌ها و جداول پیش از محاسبه
- اجرای محاسبه فقط برای خروجی‌های انتخاب‌شده و اعلام زمان/خطا
- نمایش و چاپ آنلاین یا دسته‌ای گزارش‌ها
- چندزبانگی مستقل رابط و زبان گزارش
- واحدهای پولی و تعداد اعشار قابل تنظیم
- ثبت منبع هر داده، سطح اطمینان، تاریخ مرجع و وضعیت تأیید
- کنترل خطاهای داده، تراز، منابع و مصارف، تناوب دوره و نرخ‌ها

## 8. ماتریس آزمون تطبیق و اولویت

1. **مرحله اول ـ مالی صنعتی:** پروژه جدید، تعریف محصول، CAPEX/OPEX، فروش/تولید، سرمایه در گردش، تأمین مالی، مالیات، استهلاک و گزارش‌های اصلی.
2. **مرحله دوم ـ توسعه/نوسازی:** مانده افتتاحیه، ارزش فرصت، دارایی موجود، بدهی قدیمی، سناریوهای با/بدون طرح و جریان افزایشی.
3. **مرحله سوم ـ ماژول‌های تکمیلی مالی:** تورم، مشارکت مشترک، سود تقسیمی، تسهیلات کوتاه‌مدت، کسری نقد و تحلیل هدف IRR/NPV.
4. **مرحله چهارم ـ تحلیل اقتصادی:** قیمت مرزی، ارز سایه، ضرایب تبدیل، اشتغال، آثار غیرمستقیم، ارزش افزوده و هزینه-فایده.
5. **مرحله پنجم ـ گزارش و قابلیت سازمانی:** مقایسه پروژه‌ها، گزارش‌های سفارشی، خروجی‌های چاپی، چندزبانگی و نسخه‌بندی.

هر قابلیت فقط وقتی «تکمیل» تلقی می‌شود که ورودی، منطق محاسبات، خروجی، آزمون مرجع و کنترل خطا همگی موجود باشند. برای قابلیت‌هایی که در نمونه‌های Tutorial داده عددی مرجع دارند، همان مثال باید به آزمون regression تبدیل شود.
