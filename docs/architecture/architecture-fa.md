# معماری نهایی پیشران

## تصمیم‌های قطعی

- بازار هدف: ایران و بین‌المللی
- Frontend: React + TypeScript + Vite PWA
- انتشار Frontend: GitHub Pages از طریق GitHub Actions
- Backend: Python + FastAPI روی سرویس ابری مستقل
- Database: PostgreSQL مدیریت‌شده
- Android: نصب PWA و بسته‌بندی اختیاری با PWABuilder
- AI: اتصال از Backend؛ کلیدها هرگز داخل PWA قرار نمی‌گیرند.

## مرز مسئولیت‌ها

GitHub Pages فقط فایل‌های استاتیک را میزبانی می‌کند. اجرای Python، ذخیره امن اطلاعات، پردازش مالی، صف کارهای طولانی و اتصال AI روی Backend انجام می‌شود.

## ملاحظات چندبازاری

- پشتیبانی از فارسی/انگلیسی و RTL/LTR
- واحد پول و مقیاس اعداد به‌صورت تنظیم پروژه
- تقویم شمسی و میلادی
- نرخ ارز با تاریخ مؤثر، منبع و قابلیت ثبت دستی
- مالیات، تعرفه، انرژی و مفروضات کشورمحور
- ذخیره واحد پایه و تبدیل نمایشی واحدها
- تفکیک داده واقعی، تخمینی و مفروضه
- ثبت نسخه مدل و ردپای تغییرات

## الزامات محاسباتی

هر خروجی باید شامل شناسه نسخه مدل، مفروضات، واحد، روش محاسبه، زمان محاسبه و منابع ورودی باشد. خروجی AI نباید مستقیماً مقادیر مدل را بدون تأیید کاربر تغییر دهد.

## نقشه راه

### مرحله صفر: Foundation
PWA، pipeline انتشار، API health check، PostgreSQL deployment config و اسکلت مالی.

### مرحله یک: Project Workspace
کاربران، سازمان‌ها، پروژه‌ها، نقش‌ها، مفروضات، فایل‌ها و نسخه‌بندی.

### مرحله دو: Financial Engine
جریان نقدی زمان‌بندی‌شده، NPV، IRR، MIRR، DSCR، مالیات، استهلاک، بدهی، سرمایه در گردش و تورم.

### مرحله سه: Engineering + Market
توازن جرم و انرژی، ظرفیت، تجهیزات، بازار، عرضه/تقاضا و منبع داده.

### مرحله چهار: Risk + Scenarios
سناریوهای چندمتغیره، تحلیل حساسیت، مونت‌کارلو با seed قابل بازتولید و ثبت نتایج.

### مرحله پنج: AI + Reports
RAG با منابع قابل ردیابی، دسترسی مبتنی بر نقش، گزارش PDF/Excel و بازبینی انسانی.

## امنیت و بهره‌برداری

- TLS اجباری
- کلیدها فقط در secrets سمت Backend
- CORS محدود به دامنه‌های واقعی
- احراز هویت و مجوزدهی قبل از داده واقعی
- رمزنگاری پشتیبان‌ها و برنامه بازیابی
- audit log و ثبت تغییر مفروضات
- تست واحد و تست مرجع برای فرمول‌ها
- مانیتورینگ خطا، سلامت API و هزینه AI
